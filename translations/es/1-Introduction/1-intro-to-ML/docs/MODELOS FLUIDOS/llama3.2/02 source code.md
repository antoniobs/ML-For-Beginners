Niveles de habilidad

- Óptimo: Puedo generar código fuente sin problemas, hacer refactoring y bug fixing con facilidad, y interactuar con agentes como opencode sin problemas.
- Excelente: Puedo generar código fuente con facilidad, hacer refactoring y bug fixing con rapidez, y interactuar con agentes como opencode con algunos problemas.
- Bueno: Puedo generar código fuente con cierta dificultad, hacer refactoring y bug fixing con tiempo, y interactuar con agentes como opencode con algunas limitaciones.
- Insuficiente: No puedo generar código fuente, hacer refactoring y bug fixing, o interactuar con agentes como opencode con facilidad.

Agentes

- Opencode: Puedo interactuar con opencode para obtener ayuda con códigos de programación, hacer preguntas y obtener respuestas.
- Otros agentes: Puedo interactuar con otros agentes, como GitHub, Stack Overflow, y otros, para obtener ayuda con códigos de programación y hacer preguntas.

Limitaciones

- Puedo tener dificultades al interactuar con agentes que requieren una gran cantidad de contexto o información específica.
- Puedo tener problemas al generar código fuente para lenguajes de programación que no he estudiado en profundidad.
- Puedo tener limitaciones al hacer refactoring y bug fixing en códigos de programación complejos.
