### Explicación de los Niveles de Habilidad:

1. Generación de Código Fuente:
   - Nivel: Alto
   - Detalles: Puedo ayudarte a escribir código en una amplia variedad de lenguajes de programación. Esto incluye proporcionar ejemplos de código, estructuras básicas y patrones comunes.
2. Refactoring:
   - Nivel: Medio-Alto
   - Detalles: Puedo sugerir mejoras en el código existente para mejorar la legibilidad, mantenibilidad o rendimiento. Sin embargo, mi capacidad para refactorear código complejo está limitada a sugerencias generales y patrones comunes.
3. Bug Fixing:
   - Nivel: Medio
   - Detalles: Puedo ayudarte a identificar posibles errores lógicos o de sintaxis y sugerir posibles soluciones. Sin embargo, no puedo ejecutar o probar el código, por lo que algunas soluciones pueden requerir ajustes adicionales.
4. Interacción con Agentes (e.g., OpenAI):
   - Nivel: Información y Guía
   - Detalles: Puedo explicar cómo podrían usarse agentes de IA en el desarrollo de software y discutir conceptos teóricos. Sin embargo, no puedo interactuar directamente con sistemas externos o agentes de IA en tiempo real.
