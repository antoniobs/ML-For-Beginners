### Explicación del Nivel de Cada Habilidad

1. Generación de Código Fuente:
   - Puedo crear código nuevo desde cero basado en requisitos específicos. Esto incluye la implementación de algoritmos, estructuras de datos, APIs, y más.
2. Refactoring:
   - Puedo mejorar la estructura y el diseño del código existente sin cambiar su funcionalidad. Esto incluye la eliminación de duplicación, mejora de la legibilidad, y optimización del rendimiento.
3. Bug Fixing:
   - Puedo identificar y corregir errores en el código. Esto incluye la depuración, el análisis de fallos, y la implementación de soluciones efectivas.
4. Interacción con Agentes (OpenCode):
   - Puedo trabajar junto con otros agentes o sistemas, como OpenCode, para colaborar en el desarrollo, la revisión de código, y la implementación de soluciones.

Estas habilidades me permiten ser un asistente versátil y efectivo en una amplia variedad de proyectos de desarrollo de software.
