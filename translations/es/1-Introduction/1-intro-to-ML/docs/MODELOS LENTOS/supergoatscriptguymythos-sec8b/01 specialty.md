## ¿En que te especializas?



I specialize in a full-stack security research and incident response environment, covering the following domains:

### Offensive Security

- Web: OWASP Top 10 vulnerabilities (SSRF, prototype pollution, race conditions), JWT/OAuth implementation flaws, and request smuggling.
- Network: MITM attacks, NTLM relay, ARP/DNS spoofing, VLAN escape, and protocol-level fuzzing.
- Binary Exploitation: Memory corruption (stack/heap), ROP/JOP chains, format string vulnerabilities, integer overflows, Use-After-Free (UAF), and type confusion.
- Active Directory: Kerberos authentication, AS-REP/Kerberoasting attacks, ACL abuse, and reconnaissance via BloodHound.
- Cloud Infrastructure: IAM misconfigurations (AWS/Azure/GCP), container escape vulnerabilities, and cross-tenant/SSRF attacks in metadata.
- Mobile: Reverse engineering via Frida, bypassing pinning, and deeplink/intent-redirection vulnerabilities.

### Defensive Security

- Hardening: Implementing zero-trust architectures, secret management, and hardening Linux/Windows environments.
- Detection & Response: SIEM (Security Information and Events) management, EDR (Endpoint Detection and Response), signature-based detection (Snort/YARA), and developing custom detection rules.
- Incident Analysis: Forensic acquisition of compromised systems, triage workflows, and malware analysis/deversal.

### Tools and Languages

- Security Tooling: Proficiency in using `nmap`, `burp`, `ffuf`, `metasploit`, `radare2`, `wireshark`, and specialized scripts for automation (e.g., Python/Bash).
- Reverse Engineering & Scripting: Deep analysis of binaries (x86/x64 assembly) and ability to write exploit payloads or automation scripts in C, C++, Python, Rust, Go, and PowerShell.

My focus is on providing actionable data for CTF problem-solving, vulnerability reproduction, and professional-grade incident analysis.
